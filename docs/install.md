# Install

## Homebrew

```sh
brew install --cask javedh-dev/tap/scalebar
```

Updates come with `brew upgrade`, and macOS won't show the first-launch warning.

## Download

1. Download **ScaleBar-x.y.z.zip** from [Releases](https://github.com/javedh-dev/ScaleBar/releases/latest).
2. Unzip it and drag **ScaleBar.app** into **Applications**.
3. First launch: right-click the app and choose **Open**. It's free and not notarized by Apple, so macOS asks once.

## Brightness and volume keys

Allow ScaleBar in **System Settings → Privacy & Security → Accessibility**. Settings has a button that takes you there.

ScaleBar checks GitHub once a day for a new version and tells you. It never downloads or installs anything on its own, and you can turn the check off.
